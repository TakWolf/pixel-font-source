# Pixel Font Source

[![Python](https://img.shields.io/badge/python-3.11-brightgreen?style=flat-square)](https://www.python.org)
[![PyPI](https://img.shields.io/pypi/v/pixel-font-source?style=flat-square)](https://pypi.org/project/pixel-font-source/)

A library for managing pixel font sources, including bitmap glyphs, character mappings, variants, metrics, and kerning.

## Installation

```shell
pip install pixel-font-source
```
